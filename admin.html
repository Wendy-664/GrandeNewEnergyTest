有现成的 HTML 文章？一键导入（推荐）

如果你手上已经有一个做好的文章 .html 文件，不用手工拆成几十个区块：选文件、点一下，后台会把标题、导语、正文、表格、列表、黄框、CTA、相关阅读全部填进下面的表单。填完还能改，确认无误再发布。

提示：如果文章里有图片，图片本身要先在「图片与媒体库」上传，再把路径填到对应区块里。

上传附件

PDF、规格书、图片、压缩包等任意格式，直接传到 GitHub 仓库，不需要再到网页上拖文件。

选择文件

需要已连接 GitHub。上传完成后，若勾选了「加入下载清单」，请记得点「发布到网站」。

文件名建议用英文、数字、连字符，避免空格和中文，链接更稳。同名文件再次上传会覆盖仓库里的旧版本。
通过 GitHub 接口上传的单个文件建议控制在 1 MB 以内；更大的文件请先用压缩工具处理，否则接口会报错。

图片与媒体库

换图、传图、查看仓库里已有的文件，都在这里完成。全程不需要改 HTML，也不需要打开 GitHub 网页。

① 替换站点现有图片

选中一张图 → 上传新图 → 覆盖仓库里的同名文件。全站所有引用这张图的地方会一起更新，因为 HTML 里的路径没变，只是文件内容换了。

请保持相同格式（.png 换 .png、.jpg 换 .jpg）和相近尺寸，否则版式可能跑掉。上传后按 Ctrl+F5 强制刷新才看得到新图。同名文件会直接覆盖，仓库里留有历史版本，可随时还原。

连接 GitHub 仓库

填一次即可，之后打开后台会自动记住。信息只保存在本机浏览器，不写入网站文件。

怎么拿令牌（约 2 分钟）：
1. GitHub → 右上角头像 → Settings → 左下 Developer settings
2. Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access 只选你放网站的这个仓库
4. Permissions → Repository permissions → Contents 设为 Read and write
5. 生成后复制 github_pat_... 粘贴到下面
