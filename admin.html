连接 GitHub 仓库

填一次即可，之后打开后台会自动记住。信息只保存在本机浏览器，不写入网站文件。

怎么拿令牌（约 2 分钟）：
1. GitHub → 右上角头像 → Settings → 左下 Developer settings
2. Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access 只选你放网站的这个仓库
4. Permissions → Repository permissions → Contents 设为 Read and write
5. 生成后复制 github_pat_... 粘贴到下面
